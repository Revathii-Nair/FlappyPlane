# Flappy Plane

A 2D flying game built using the Godot Engine and C#. Pilot a small plane through an endless sequence of scrolling obstacles, manage your plane and try to beat your highest score.

## Features

- **Physics-Based Flight:** The plane continuously falls due to gravity and is propelled upward whenever the player presses the spacebar.
- **Endless Obstacles:** Pipes spawn dynamically off-screen and scroll leftward. Passing safely between them awards points.
- **Persistent High Scores:** Scores are saved locally using custom Godot Resources
- **Animation:** Plane animation and Fade‑in/out animations between menus and gameplay

## Controls

- **Fly / Jump:** `Spacebar` .
- **Menu Navigation:** `ESC`.

## Tech Stack

- **Engine:** Godot mono 4.6.2 (.NET)
- **Language:** C#

## How to Play

1. Clone or download this repository.
2. Open the **Godot mono Engine 4.6.2 (.NET)** and import the project by selecting the `project.godot` file.
3. Click the **"Build"** button in Godot to compile.
4. Press `F5` to run the project.
